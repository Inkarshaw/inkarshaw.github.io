4. Sector diagram settings

Sectors are spaced evenly around the tower anchor. When a C-Trace report supplies only an azimuth (such as 160°), the 120° wedge width remains a display assumption, not a carrier-confirmed beamwidth. A reported approximate distance can be used to set the illustrative wedge radius, but does not identify a unique handset position.

Interpretation: A reported coordinate is not necessarily a handset GPS fix or a tower site. LBS Type C is preserved exactly as reported; its technical meaning must be confirmed with the provider. Neither the CGI nor the coordinates disclose sector azimuth, coverage radius, or the active antenna direction by themselves. All wedges are hypothetical until independently verified.
