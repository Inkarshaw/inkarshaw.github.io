DAILY SITUATION REPORT (DSR) MAKER

Supports multiple offence heads and multiple cases on the same day. Duty Roster is left out.

Basic Information
The summary table is generated automatically from all cases added in the Cases / Heads tab, together with NBW, PRC and Forecast counts.
Cases / Offence Heads
Add as many cases as required. Cases with the same head are grouped together automatically in the final report. Different heads are shown as separate sections.
