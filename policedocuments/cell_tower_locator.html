📡 Cell Tower Locator

Find a mapped cell-location estimate from network identifiers or your own tower-coordinate records. One Cell ID is not globally unique, and a mapped cell is not necessarily the physical mast.

1. Enter cell details

Paste a Cell ID or a combined 5G NCGI (6-digit MCC/MNC followed by 9 hexadecimal NCI digits). The combined code fills MCC, MNC and NCI; you still need a separate TAC for online lookup. A local CSV may contain multiple matches.

For 5G combined codes, paste the whole identifier; MCC/MNC and NCI will be decoded automatically.

Online database lookup (OpenCellID)

Get a key from OpenCellID. The request sends these network identifiers and your key directly from this browser to OpenCellID. Some browsers may block cross-origin API requests; the offline CSV method below works without an API key.

2. Search local tower records (no upload)

Select an OpenCellID CSV export or your own CSV with cellid,latitude,longitude columns. OpenCellID exports also support radio,mcc,net,area,cell,lon,lat. File contents are processed in this browser and are not uploaded to this website.

Maximum file size: 30 MB

Using results for investigation

For reliable identification, obtain the relevant operator's Cell ID–site list, date-specific tower details, sector/azimuth details and certified records. Network identifiers are reused, reconfigured and can refer to sectors rather than a unique physical tower. Public coordinates may be inaccurate or outdated; do not treat this lookup as conclusive legal evidence.
