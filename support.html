Support and corrections

Help improve the accuracy and usability of ClearExams. Report a broken page, a wrong answer, a missing source, or a display problem using the public issue tracker.

Report a public issue

What to include

Include the page URL, exam/year or question number, what went wrong, your proposed correction, and a link to an official paper or textbook when possible. For display bugs, mention the browser and device type without posting device identifiers.

Privacy and security

GitHub issues are public. Never include passwords, phone numbers, admit cards, addresses, case records, private documents or other personal information. Do not post a security vulnerability with sensitive exploitation details in a public issue. A dedicated private support channel is not published on this website yet; private reports should not be submitted through this public tracker.

Source and coverage questions

See our textbook coverage tracker, PYQ text coverage, and editorial policy to distinguish draft practice from verified source material.
