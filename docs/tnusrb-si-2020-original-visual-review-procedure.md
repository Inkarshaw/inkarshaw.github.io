## Verification on a trusted reviewer device

1. Open [the original-source visual review workbench](../tnusrb-si-2020-source-review.html). It is noindex and never calculates student marks.
2. Download the original General Candidates Series C booklet directly from TNUSRB when accessible; manually inspect cover, date, paper type, printed question numbering and every option. A PDF magic header, file name or secondary scan alone does not prove the source is authentic.
3. Load it in the local-only PDF viewer. It accepts 100 bytes–80 MB with a PDF signature, creates a browser object URL, and does **not** upload any bytes. Embedded PDF support depends on device/browser.
4. For each Q47/Q84/Q95/Q103, record the PDF page, printed question number, exact source filename/URL and discrepancies. Mark the five manual checks only after observing the Series C cover, stem, choices, original diagram/matrix and separately published C-series final-key token. A checked box is a reviewer's statement, not board certification.
5. Browser-local checked status additionally requires board booklet selection, matching question number, valid PDF page and substantive review notes. Secondary scans and cross-Series D reconstructions remain drafts.
6. Export the source-bound four-question JSON for an independent second reviewer. Imported records from an older or changed question/option version lose old checkmarks; notes are retained. Exports never contain the PDF itself.
