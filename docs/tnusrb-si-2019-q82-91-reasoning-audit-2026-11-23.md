# TNUSRB SI 2019 recruitment / January 2020 Series C — Q82–91 reasoning audit

**Date:** 23 November 2026.

This is a verification/improvement pass on the *existing* 140-question Series C psychology section, not a new source transcription or a second SI paper. User-supplied questions Q1–81, Q92–120 were reconciled in earlier passes. Q82–91 are already playable, but students lacked post-check working for several quantitative and coding problems.

## Editorial worked solutions

- **Q82 code table (C):** The same ten words/ten scrambled digit strings uniquely constrain the letter–digit bijection: A=2, B=5, L=3, M=4, S=8, Q=6, R=9, P=1, T=0, N=7. Thus 5678 = BQNS, option C.
- **Q83 performance (B):** Best percentage is Q on paper V, 56/80 = 70%; P's highest is 65% on paper II.
- **Q89 pie chart bilingual conflict (A/C):** English asks for 105 marks: Hindi's 70° sector out of 360° on total marks 540 equals **105** (C). A separate 2019 General Candidates **Series D** paper reproduction with matching pie chart and answers has Tamil text asking **which subject had the highest marks**: Mathematics has the biggest sector at 90° = 135 marks (A). The separately published **Series C** final key already gives **A/C**, so both formulations are consistent with the two accepted options. The explanation for *why the board* officially accepted both has **not** been proven; original Series C printed bilingual page not visually certified. Retain accepted answers A and C, preserve provisional scoring, do **not** claim the Study Tamil text is original Series C text.
- **Q90 train schedule (B):** Station arrival 10:25 + 28 minutes = 10:53, scheduled train arrival 11:25 − 42 = 10:43, difference 10 minutes.
- **Q91 population (B):** 45+ groups add to 30%; if 30% is 45m, 18% aged 31–45 is 27m.
