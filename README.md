# ClearExams repository structure

This GitHub Pages repository is organised by responsibility so public pages, code, data and downloadable resources are easier to maintain.

## Main areas

- `index.html` and the other root `.html` files are stable public entry pages.
- `assets/css/` contains shared stylesheets.
- `assets/js/` contains shared JavaScript.
- `data/exams/` contains exam catalog, notification and post metadata.
- `data/quizzes/` contains quiz and mock-test datasets.
- `resources/syllabus/pdfs/` contains downloadable syllabus PDFs.
- `resources/syllabus/text/` contains syllabus text used by the reader.
- `tnpsc/mocks/` contains the TNPSC Group IV mock-test series.
- `exam/`, `tnpsc/`, `tnusrb/` and `upsc/` contain subject/exam pages.
- `current-affairs/` contains daily current-affairs PDFs and publishing metadata.
- `policedocuments/`, `policepassportgenerator/` and `mycases/` are kept as separate application areas.
- `scripts/` contains repository automation scripts.
- `.github/workflows/` contains GitHub Actions workflows.

## Compatibility

The former root TNPSC Group IV mock URLs remain as small redirect pages so existing bookmarks keep working. New links and the sitemap use `/tnpsc/mocks/`.
